# Contributing

Contributions that improve numerical correctness, portability, documentation, or
tests are welcome.

Before opening a pull request:

1. Keep the project independent of editor plugins and hosted services.
2. Add tests for every numerical or behavioral change.
3. Run `python -m pytest`, `ruff check .`, and `ruff format --check .`.
4. Do not add sensitive data or code whose license is incompatible with MIT.
